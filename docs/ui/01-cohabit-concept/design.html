0. 一句话定位

用包豪斯的硬边几何，讲一个关于“边界”的温和产品。

米白纸面 + 炭黑墨线 + 爱马仕橙，三色；网格纸打底；2px 描边 + 硬投影代替柔和阴影；大字排版；动效一律“快进慢停”；唯一的柔性元素是广场的橙色光和会晃的吊牌。

首帧只留 Logo 与标题，卡片四周是更深的米色网格，— SCROLL 提示可以下滑。

1. 设计原则（五条，决定所有细节）

  1. 纸与墨：页面是纸（米白 + 56px 网格），元素是印上去的墨块（2px 黑边、实色填充、硬投影）。不用磨砂、不用多层阴影、不用渐变按钮。
  2. 三色纪律：橙只做“注意力”，墨只做“结构”，米白只做“呼吸”。一屏里橙色面积不超过 15%。
  3. 硬边 + 一处柔光：所有卡片、按钮、输入框都是 2–4px 圆角；只有转盘舞台允许大面积橙色柔光，形成唯一的高光区域。
  4. 动效是位移，不是特效：元素只做 8–26px 的短位移 + 透明度，时长 180–860ms，曲线 cubic-bezier(0.16, 1, 0.3, 1)；不做弹跳（除磁吸按钮的弹簧）。
  5. 信息像标签：所有小标题都是“带框的标签”（eyebrow），所有数字都用大字号 + 小单位，读起来像印刷品。

2.2 用色规则

  • 橙底黑字：橙 #FF8A00 上的文字一律用 #2B1B08（对比 7:1）。白字在橙上只有 2.1:1，禁止。
  • 小字橙：小于 14px 的橙色文字改用 --coral-dark（4.6:1）；大标题、数字、图标才用纯橙。
  • 深色块：--ink 底 + 米白字；深色块里的橙用 --amber（更亮），不用 --coral。
  • 禁用：粉紫渐变、玻璃高光按钮、彩色阴影（阴影只用墨色低透明度）。

3.3 排版细节

  • 中文标题不使用伪斜体；强调靠颜色（橙）和字重，不靠 italic。
  • 英文标签统一大写 + 宽字距（0.14–0.2em），像印刷标签。
  • 行高：标题 0.96–1.05，正文 1.65–1.85；行长控制在 34–42 个汉字。
  • 数字与单位之间不断行；百分比用 <em> 缩小到 55%。

5. 组件规格

5.1 按钮（三型 + 磁吸）

基础 .btn
- 高 46px / 小号 38px，左右 22px / 16px；字号 14 / 700，字距 0.02em
- 边框 2px 墨；圆角 2px；硬投影 4px 4px 0
- hover：translate(-2px,-2px) + 投影变 6px 6px 0，180ms
- active：translate(2px,2px) + 无投影，90ms
- disabled：opacity .55，无位移

变体
| 变体 | 底 | 字 | 场景 |
|---|---|---|---|
| primary | #FF8A00 | #2B1B08 | 主行动（开始完善画像 / 打招呼） |
| dark | #363636 | #FFF2DF | 深色区块内的主行动 |
| ghost | 透明 | 墨 | 次级行动（先看看广场） |

磁吸（MagneticButton / Magnet）
- 外层占位不动，内层 translate 跟随指针：offset = (指针 - 中心) / strength × 衰减
- 默认 padding 90–110、strength 2.4–3、maxOffset 12–18、scale 1.02
- 弹簧 stiffness 170 / damping 16 / mass 1；离开后回弹
- 只在 pointer: fine 与 prefers-reduced-motion: no-preference 时启用
- 命中区域比按钮大 90px，形成“靠近就被吸”的手感

5.2 导航（PillNav 药丸导航）

6.2 进场动画（ScrollExpand 式）

结构：.entry（170vh 轨道）→ .entry__stage（sticky，top 76，高 100vh-76）→ .entry__frame → .entry__poster。

滚动约半屏时，卡片从 44%×62% 撑到接近满屏，标题随展开略微放大。

首帧：纸面网格 + 居中标题卡（44%×62% 视口），卡内自上而下：COHABIT · 校园组寝 标签 → 48 网格 Logo → 两行标题（第二行橙色）→ 一句副文案；卡片底部 18px 处一条 — SCROLL 向下滚动，进入网站。

滚动映射（raw = scrollY / innerHeight，p = clamp01(raw / 0.85)）：

e   = smooth(0, 0.84, p)            // 展开进度
ix  = 28 × (1 - e)  %               // 左右内缩
iy  = 19 × (1 - e)  %               // 上下内缩
fr  = 3  × (1 - e)  px              // 圆角
edge = 1 - smooth(0.72, 0.84, p)×1.4  // 描边淡出
post = smooth(0.9, 1.15, raw)        // 标题卡内容淡出
  • 卡片内容同步 scale(1 + 0.16e)，随展开略微放大
  • post 阶段内容上移 18px 并淡出，避免与主页 Hero 标题“撞车”
  • 进度用 0.12 低通滤波平滑，滚轮一格不会跳
  • 动画期间页头 opacity: 0（保留占位，不跳版）

降级：首次以外、≤900px、prefers-reduced-motion → 不渲染入场层，直接主页。

6.3 滚动揭示（Scroll Reveal）

  • IntersectionObserver：threshold 0.08，rootMargin 0 0 -6% 0
  • 初始 opacity: 0; translateY(26px)；进入后 560ms / 860ms 淡入上移
  • 同容器内按顺序加 55ms 延迟（最多 260ms），形成瀑布
  • 只触发一次；路由切换 / 列表筛选后由 MutationObserver 自动接管
  • 变体：data-reveal="left|right|scale"

6.4 文本动画

  • ShinyText：标题第二行“再住一起。”用一条 100° 的浅橙光带扫过（#FF8A00 底 + #FFC4A0 光），4.4s 一轮，光带宽度 14%，柔化 0.86，辉光 0.1，background-clip: text
  • ScrollFloat：收尾 CTA 的标题按词上浮（float / words / stagger 35ms / ease-out）
  • 标题遮罩上升：广场、匹配 H1 用 overflow:hidden + translateY(108%) → 0 1000ms，第二行延迟 90ms
  • 数字递增：分数、统计用 requestAnimationFrame 从 0 缓动到目标值（600–900ms）

6.5 转盘（CircularCarousel）

  • 圆柱排列：step = 360/n，R = max((cardW+gap)/(2sin(π/n)), cardW×0.72)
  • 相机 translateZ(-R) rotateX(-7°)；每张卡 rotateY(base) translateZ(R)
  • 自动适配：投影四角求包围盒，fit = min(1, 0.88w/2maxX, 0.86h/2maxY)，写回 perspective 与 scale
  • 运动：rAF 弹簧，k=120, c=2√k；拖拽 perPixel = 180/(πR·fit)；松手吸附最近卡
  • 自动漂移 4°/s，悬停暂停；方向键 / 回车 / 点侧卡切换；背面 visibility:hidden
  • 卡片深度：((1-cosθ)/2)^0.8 × depthFade 映射到遮罩透明度

所有断点检查：无横向溢出（scrollWidth === clientWidth），触控目标 ≥40px。

9. 无障碍与性能

  • 语义：header / nav / main / section / footer；main 有 tabindex="-1"，路由后聚焦
  • 键盘：转盘 ←/→、导航 Esc、按钮可见焦点环（橙深色 2px）
  • 对比：文字组合均 ≥4.5:1；橙色底一律深字
  • 动效：prefers-reduced-motion 关闭入场、揭示、漂移、吊牌摆动、流光
  • 性能：转盘只更新 transform / CSS 变量；揭示使用 IO 不用 scroll；图片用 SVG；首屏骨架内联，避免白屏
  • 资源：字体 3 族（Space Grotesk / Inter / Noto Sans SC），display=swap
