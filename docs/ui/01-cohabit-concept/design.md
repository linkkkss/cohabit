## 0. 一句话定位

**用包豪斯的硬边几何，讲一个关于“边界”的温和产品。**

米白纸面 + 炭黑墨线 + 爱马仕橙，三色；网格纸打底；2px 描边 + 硬投影代替柔和阴影；大字排版；动效一律“快进慢停”；唯一的柔性元素是广场的橙色光和会晃的吊牌。

![入场首帧：Logo + 两行标题](ui-design/entry.png)

*首帧只留 Logo 与标题，卡片四周是更深的米色网格，`— SCROLL` 提示可以下滑。*

## 1. 设计原则（五条，决定所有细节）

1. **纸与墨**：页面是纸（米白 + 56px 网格），元素是印上去的墨块（2px 黑边、实色填充、硬投影）。不用磨砂、不用多层阴影、不用渐变按钮。
2. **三色纪律**：橙只做“注意力”，墨只做“结构”，米白只做“呼吸”。一屏里橙色面积不超过 15%。
3. **硬边 + 一处柔光**：所有卡片、按钮、输入框都是 2–4px 圆角；只有转盘舞台允许大面积橙色柔光，形成唯一的高光区域。
4. **动效是位移，不是特效**：元素只做 8–26px 的短位移 + 透明度，时长 180–860ms，曲线 `cubic-bezier(0.16, 1, 0.3, 1)`；不做弹跳（除磁吸按钮的弹簧）。
5. **信息像标签**：所有小标题都是“带框的标签”（eyebrow），所有数字都用大字号 + 小单位，读起来像印刷品。

*配色、字号阶梯、按钮三态、几何规则一览。*

### 2.2 用色规则

- **橙底黑字**：橙 `#FF8A00` 上的文字一律用 `#2B1B08`（对比 7:1）。白字在橙上只有 2.1:1，禁止。
- **小字橙**：小于 14px 的橙色文字改用 `--coral-dark`（4.6:1）；大标题、数字、图标才用纯橙。
- **深色块**：`--ink` 底 + 米白字；深色块里的橙用 `--amber`（更亮），不用 `--coral`。
- **禁用**：粉紫渐变、玻璃高光按钮、彩色阴影（阴影只用墨色低透明度）。

### 2.3 对比度基线

| 组合 | 比值 |
|---|---|
| `#363636` on `#FFF2DF` | ≈ 10.4:1 |
| `#746A5C` on `#FFF2DF` | ≈ 4.7:1 |
| `#A85A00` on `#FFF2DF` | ≈ 4.6:1 |
| `#2B1B08` on `#FF8A00` | ≈ 7.0:1 |
| `#FFF4E2` on `#363636` | ≈ 10.9:1 |

## 3. 字体与排版

### 3.1 字体

| 角色 | 字体栈 |
|---|---|
| 展示 / UI / 数字 | `"Space Grotesk", "Noto Sans SC", "PingFang SC", sans-serif` |
| 正文 | `"Inter", "Noto Sans SC", "PingFang SC", sans-serif` |
| 大号汉字（画像 initials） | `"Songti SC", "Noto Serif SC", "SimSun", serif` |

> Space Grotesk 负责几何感（数字、英文标签、按钮），中文回落到 Noto Sans SC；仅“画像大字”保留宋体，制造一处书法对比。

### 3.2 字号阶梯

| 层级 | 规格 |
|---|---|
| Hero 标题 `.display` | `clamp(40px, 6.6vw, 72px)` / 700 / `-0.02em` / `0.96` |
| 页面 H1（广场/匹配/画像） | `clamp(31px, 4.2vw, 51px)` / 700 / `-0.03em` |
| 区块 H2 | `clamp(28px, 4vw, 40px)` / 700 / `-0.02em` / `1.05` |
| 卡片标题 | 17–22px / 600–700 |
| 正文 | 15px / 1.65 |
| Lede | 16px / 1.8 / 最大 540px |
| 标签 eyebrow | 10.5px / 700 / `0.2em` / 大写 |
| 辅助说明 `.fine` | 12px / 1.6 / `--muted` |
| 数字 | 600–700，单位降一级并缩小（`92%` → 92 大、% 小） |

### 3.3 排版细节

- 中文标题**不使用**伪斜体；强调靠颜色（橙）和字重，不靠 italic。
- 英文标签统一大写 + 宽字距（`0.14–0.2em`），像印刷标签。
- 行高：标题 0.96–1.05，正文 1.65–1.85；行长控制在 34–42 个汉字。
- 数字与单位之间不断行；百分比用 `<em>` 缩小到 55%。

## 5. 组件规格

### 5.1 按钮（三型 + 磁吸）

**基础 `.btn`**
- 高 46px / 小号 38px，左右 22px / 16px；字号 14 / 700，字距 `0.02em`
- 边框 2px 墨；圆角 2px；硬投影 `4px 4px 0`
- hover：`translate(-2px,-2px)` + 投影变 `6px 6px 0`，180ms
- active：`translate(2px,2px)` + 无投影，90ms
- disabled：`opacity .55`，无位移

**变体**
| 变体 | 底 | 字 | 场景 |
|---|---|---|---|
| `primary` | `#FF8A00` | `#2B1B08` | 主行动（开始完善画像 / 打招呼） |
| `dark` | `#363636` | `#FFF2DF` | 深色区块内的主行动 |
| `ghost` | 透明 | 墨 | 次级行动（先看看广场） |

**磁吸（`MagneticButton` / `Magnet`）**
- 外层占位不动，内层 `translate` 跟随指针：`offset = (指针 - 中心) / strength × 衰减`
- 默认 `padding 90–110`、`strength 2.4–3`、`maxOffset 12–18`、`scale 1.02`
- 弹簧 `stiffness 170 / damping 16 / mass 1`；离开后回弹
- 只在 `pointer: fine` 与 `prefers-reduced-motion: no-preference` 时启用
- 命中区域比按钮大 90px，形成“靠近就被吸”的手感

### 5.2 导航（PillNav 药丸导航）

- 结构：`nav > bar(2px 墨边 + 4px 硬投影) > track > item`；底为实色 `--paper`（非玻璃）
- 尺寸：高 44px，item 左右 18px，字号 14 / 600
- 当前项：实心墨色胶囊，文字 `--paper`；滑块用 transform + width 过渡（220–420ms 弹簧）
- 徽标：方形 2px 墨框 + 橙底 + 深色数字（`2`、`9+`）
- 折叠：≤900px 收成“菜单”按钮（黑边胶囊 + 汉堡），展开为**全宽面板**（`fixed; top:76px; left/right:14px`），行高 48px，当前行橙底
- 键盘：Tab 可达，Esc 关闭，展开时焦点进入面板

### 5.3 页头 / 页脚

- 页头 sticky，高 76px（≤900 为 68px）；底部 2px 墨线；实色 `--paper`，不用模糊
- 左：36px 方形 Logo（橙底、2px 墨框、`3px 3px 0` 投影、C 字标），+ “Cohabit” 20px
- 中：药丸导航，绝对居中（`grid: 1fr auto 1fr`）
- 右：40px 方形图标按钮（搜索、通知带橙点）、用户胶囊（32px 头像 + 姓名 + 完成度）
- 页脚：顶部 2px 墨线；左侧 40px “Cohabit.” 字标 + 一句 slogan + `UI CONCEPT · CREAM / CHARCOAL / HERMES ORANGE`；右侧三列链接（产品 / 关于 / 设计）；底部版权行

### 5.4 个人信息卡片（ProfileCard）

- 外框 2px 墨边、圆角 20px、实色 `--paper-raised`、硬投影 `8px 10px 0 rgba(54,54,54,.14)`
- 内部：10px 内边距 → 画像区（4:5）→ 1.5px 顶线 → 信息带（姓名 22px / 学院 13px）→ 底部（handle + 状态点 + 联系胶囊）
- 画像区：橙色圆盘（`--coral`，2px 墨边）+ 虚线环 + 宋体大字（96px）；或自定义 `#portrait` 插槽
- 交互：指针进入时 3D 倾斜（最大 9°）+ 画像 10px 视差 + 高光跟随；离开回正
- 深色版：`--ink` 底、米白 2px 描边、米白文字、橙色大字

### 5.5 广场转盘卡（三色吊牌式立卡）

- 卡 250×330，圆角 22px，无描边，软投影
- **正面**：米白 `linear-gradient(165deg,#FFF8EC,#F7EAD6 55%,#EFDCC0)`
- **左侧**：炭黑 `linear-gradient(165deg,#4C4C4C,#3A3A3A 55%,#2C2C2C)`，大字橙
- **右侧**：橙 `linear-gradient(165deg,#FFA32B,#FF8A00 55%,#E97A00)`，大字近黑
- 卡面元素：左上“匹配度” 9.5px、右上白色胶囊 `92%`、中间宋体大字 86px、底部姓名 17px + 学院 11.5px
- 侧面卡只显示大字与 score 胶囊；正面卡全信息
- 颜色由“环上偏移”决定：正面偏移 0；逆时针半圈为左（炭黑），顺时针为右（橙）

### 5.6 物理吊牌（SwingTag，今日匹配）

- 结构：支点钉 → 织带 26×78 → 金属夹 54×16 → 卡片（打孔 18px）
- 卡片 244 宽，圆角 18px，2px 墨边，深色版 `#3D3A35 → #211F1C`
- 内容：`TODAY · 今日匹配` 9.5px 宽字距、`92%` 胶囊、橙色宋体大字、姓名/学院、结束线
- 物理：`θ'' = -kθ - cθ'`，`k = 46`，`c = 3.4`；拖动灵敏度 `0.3°/px`，摆角限制 ±52°
- 松手按角速度继续摆动，约 3 次回摆后停（实测 33.6° → 24.4° → −7.7° → −0.4°）
- 光标 `grab / grabbing`；`prefers-reduced-motion` 下不启动

### 5.7 标签 / 表单 / 骨架

- `.chip`：1.5px 墨边、2px 圆角、4×10px 内距、12px/600；选中态用橙底
- `.eyebrow`：带框标签；深色底上改为透明底 + 米白框 + 米白字
- 输入：2px 墨边、2px 圆角、46px 高、focus 时橙底 2px 内阴影
- 骨架：`index.html` 内联首屏骨架（导航胶囊、标题条、橙色 CTA 块、画像块、三张卡），斜向流光 1.9s；列表骨架 2.2s，`prefers-reduced-motion` 关闭

## 6. 动效系统

### 6.1 曲线与时长

| 用途 | 值 |
|---|---|
| 主缓动 | `cubic-bezier(0.16, 1, 0.3, 1)`（快进慢停） |
| 次级 | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 弹簧（磁吸/悬停） | `cubic-bezier(0.34, 1.56, 0.64, 1)` |
| 微交互 | 90–180ms |
| 常规过渡 | 200–300ms |
| 大块入场 | 560–860ms |
| 路由切换 | ≤200ms |

### 6.2 进场动画（ScrollExpand 式）

**结构**：`.entry`（170vh 轨道）→ `.entry__stage`（sticky，top 76，高 `100vh-76`）→ `.entry__frame` → `.entry__poster`。

![展开中段：卡片向四周撑开](ui-design/entry-mid.png)

*滚动约半屏时，卡片从 44%×62% 撑到接近满屏，标题随展开略微放大。*

**首帧**：纸面网格 + 居中标题卡（44%×62% 视口），卡内自上而下：`COHABIT · 校园组寝` 标签 → 48 网格 Logo → 两行标题（第二行橙色）→ 一句副文案；卡片底部 18px 处一条 `— SCROLL 向下滚动，进入网站`。

**滚动映射**（`raw = scrollY / innerHeight`，`p = clamp01(raw / 0.85)`）：
```
e   = smooth(0, 0.84, p)            // 展开进度
ix  = 28 × (1 - e)  %               // 左右内缩
iy  = 19 × (1 - e)  %               // 上下内缩
fr  = 3  × (1 - e)  px              // 圆角
edge = 1 - smooth(0.72, 0.84, p)×1.4  // 描边淡出
post = smooth(0.9, 1.15, raw)        // 标题卡内容淡出
```
- 卡片内容同步 `scale(1 + 0.16e)`，随展开略微放大
- `post` 阶段内容上移 18px 并淡出，避免与主页 Hero 标题“撞车”
- 进度用 0.12 低通滤波平滑，滚轮一格不会跳
- 动画期间页头 `opacity: 0`（保留占位，不跳版）

**降级**：首次以外、≤900px、`prefers-reduced-motion` → 不渲染入场层，直接主页。

### 6.3 滚动揭示（Scroll Reveal）

- IntersectionObserver：`threshold 0.08`，`rootMargin 0 0 -6% 0`
- 初始 `opacity: 0; translateY(26px)`；进入后 560ms / 860ms 淡入上移
- 同容器内按顺序加 55ms 延迟（最多 260ms），形成瀑布
- 只触发一次；路由切换 / 列表筛选后由 MutationObserver 自动接管
- 变体：`data-reveal="left|right|scale"`

### 6.4 文本动画

- **ShinyText**：标题第二行“再住一起。”用一条 100° 的浅橙光带扫过（`#FF8A00` 底 + `#FFC4A0` 光），4.4s 一轮，光带宽度 14%，柔化 0.86，辉光 0.1，`background-clip: text`
- **ScrollFloat**：收尾 CTA 的标题按词上浮（float / words / stagger 35ms / ease-out）
- **标题遮罩上升**：广场、匹配 H1 用 `overflow:hidden` + `translateY(108%) → 0` 1000ms，第二行延迟 90ms
- **数字递增**：分数、统计用 `requestAnimationFrame` 从 0 缓动到目标值（600–900ms）

### 6.5 转盘（CircularCarousel）

- 圆柱排列：`step = 360/n`，`R = max((cardW+gap)/(2sin(π/n)), cardW×0.72)`
- 相机 `translateZ(-R) rotateX(-7°)`；每张卡 `rotateY(base) translateZ(R)`
- 自动适配：投影四角求包围盒，`fit = min(1, 0.88w/2maxX, 0.86h/2maxY)`，写回 `perspective` 与 `scale`
- 运动：rAF 弹簧，`k=120, c=2√k`；拖拽 `perPixel = 180/(πR·fit)`；松手吸附最近卡
- 自动漂移 4°/s，悬停暂停；方向键 / 回车 / 点侧卡切换；背面 `visibility:hidden`
- 卡片深度：`((1-cosθ)/2)^0.8 × depthFade` 映射到遮罩透明度

### 6.6 其他交互

| 交互 | 反馈 |
|---|---|
| 磁吸按钮 | 跟随指针 + 放大 1.02，离开回弹 |
| 卡片悬停 | 上移 2px + 投影加深（列表卡）；画像卡 3D 倾斜 |
| 导航项 | 胶囊滑块 220–420ms 弹性移动；悬停文字变墨 |
| 打招呼 | 按钮文案 `打招呼 → 已打招呼`，插入到“已邀请”列表 |
| 补全画像 | 点击 todo → 进度 +4%，提示“已保存，画像完整度更新了” |
| 筛选 | 结果数变化 + 列表淡入；空态给“放宽条件”入口 |
| 路由切换 | 页面淡入 180ms；滚动回顶 |

## 7. 页面布局规格

### 7.1 `/` 首页

1. **入场**（170vh，见 6.2）

## 9. 无障碍与性能

- 语义：`header / nav / main / section / footer`；`main` 有 `tabindex="-1"`，路由后聚焦
- 键盘：转盘 ←/→、导航 Esc、按钮可见焦点环（橙深色 2px）
- 对比：文字组合均 ≥4.5:1；橙色底一律深字
- 动效：`prefers-reduced-motion` 关闭入场、揭示、漂移、吊牌摆动、流光
- 性能：转盘只更新 transform / CSS 变量；揭示使用 IO 不用 scroll；图片用 SVG；首屏骨架内联，避免白屏
- 资源：字体 3 族（Space Grotesk / Inter / Noto Sans SC），`display=swap`
